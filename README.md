# 米国株 大口投資家動向・セクター強弱ダッシュボード

プログラミング経験がなくても、この手順どおりに進めれば、自分専用のWebサイト（アプリ）を無料で公開できます。サイトを開くたびに、その場で最新の米国株データを取得して表示する仕組みです。

このダッシュボードでは、次の情報が確認できます。

- 🧭 主要指数・資産（ダウ30・S&P500・ナスダック100・ビットコイン・金）の値動き
- 🏭 11セクターETFの強弱ランキング（グラフ）
- 🕵️ 内部者クラスター買い（複数の役員が同時期に自社株を購入した銘柄）
- 🚀 ARK Investの日次売買動向（買い増し・売却の上位銘柄）
- 🔗 主要資産どうしの値動きの相関マトリクス（ヒートマップ）
- 📅 期間セレクター（1日／1週間／1ヶ月で表示を切り替え）

⚠️ 本サイトは事実整理であり、投資助言ではありません。個別銘柄の売買判断はご自身の責任で行ってください。

## 1. まず用語を簡単に説明します

プログラミング未経験の方向けに、これから出てくる言葉を先に説明します。

- **リポジトリ (repository)**：GitHub上にファイルを保管しておく「フォルダ」のようなものです。
- **app.py**：このアプリの本体（プログラム）が書かれたファイルです。中身を編集する必要はありません。
- **requirements.txt**：「このアプリを動かすには、こういう道具（Pythonのライブラリ）が必要です」という買い物リストのようなファイルです。Streamlit Community Cloud はこのファイルを読んで、必要な道具を自動的にそろえてくれます。
- **.streamlit/config.toml**：アプリの見た目（ダークテーマなど）を設定するファイルです。`.streamlit` という名前のフォルダの中に `config.toml` というファイルを置く、という決まりになっています。
- **デプロイ (deploy)**：作ったアプリをインターネット上に公開して、誰でも（またはあなただけが）アクセスできるようにすることです。

このフォルダには次の4つのファイルが入っています。

| ファイル名 | 役割 |
| --- | --- |
| `app.py` | アプリ本体のプログラム |
| `requirements.txt` | 必要なライブラリの一覧 |
| `config.toml` | 画面のダークテーマ設定（`.streamlit`フォルダに入れて使います） |
| `README.md` | この説明書 |

## 2. 準備するもの

- GitHubアカウント（作成中とのことなので、作成完了させてください）
- Streamlit Community Cloudアカウント（作成中とのことなので、作成完了させてください。Streamlit Community CloudはGitHubアカウントでログインする仕組みなので、GitHubアカウントが先に必要です）

---

## 3. GitHubに新しいリポジトリを作る

1. ブラウザで [github.com](https://github.com) を開き、ログインします。
2. 画面右上の「**+**」アイコンをクリックし、「**New repository**」を選びます。
3. 「**Repository name**」欄に、好きな名前を入力します（例：`us-stock-dashboard`）。半角英数字とハイフンが無難です。
4. 「**Public**」を選択します（Streamlit Community Cloudの無料枠はPublicリポジトリが基本です）。
5. 「Add a README file」などのチェックボックスは、**すべてチェックを入れないまま**にしてください（このあと自分でファイルをアップロードするためです）。
6. 一番下の「**Create repository**」ボタンをクリックします。

これで空っぽのリポジトリ（保管フォルダ）ができました。

---

## 4. ファイルをリポジトリにアップロードする

### 4-1. app.py・requirements.txt・README.md をアップロード

1. 作成したリポジトリのページで、「**Add file**」ボタン（画面右上あたり）をクリックし、「**Upload files**」を選びます。
2. このフォルダにある `app.py`・`requirements.txt`・`README.md` の3つのファイルを、アップロード画面にドラッグ＆ドロップします（またはクリックしてファイルを選択します）。
3. 画面下の「**Commit changes**」というボタンをクリックします（コメント欄は空のままで問題ありません）。

これで3つのファイルがリポジトリの一番上の階層（ルート）に置かれます。

### 4-2. .streamlit/config.toml をアップロード（ダークテーマ設定・任意ですが推奨）

このファイルだけは、`.streamlit` という名前の「フォルダの中」に置く必要があるため、ドラッグ＆ドロップではなく、次の方法で作成します。

1. リポジトリのページで、「**Add file**」→「**Create new file**」をクリックします。
2. ファイル名を入力する欄に、そのまま次のように入力します。

   ```
   .streamlit/config.toml
   ```

   （スラッシュ `/` を入力すると、GitHubが自動的に `.streamlit` というフォルダを作ってくれます。）
3. 下に表示される編集エリアに、このフォルダにある `config.toml` ファイルの中身をすべてコピーして貼り付けます。
4. 画面下の「**Commit changes**」をクリックします。

これでリポジトリの中身は次のような構成になります。

```
あなたのリポジトリ/
├── app.py
├── requirements.txt
├── README.md
└── .streamlit/
    └── config.toml
```

※ この `.streamlit/config.toml` を省略しても、アプリ自体は動作します（画面内のCSSで最低限のダーク調にしています）。ただし、より確実にダークテーマを固定したい場合は、この手順を行ってください。

## 5. Streamlit Community Cloudでデプロイ（公開）する

1. ブラウザで [share.streamlit.io](https://share.streamlit.io) を開きます。
2. 「**Continue to sign-in**」→「**Continue with GitHub**」の順にクリックし、GitHubアカウントでログインします。
3. 初回は、GitHubリポジトリへのアクセスを許可するか聞かれるので、「**Authorize streamlit**」をクリックします。
4. ログインすると、あなたの「ワークスペース」画面が表示されます。画面右上の「**Create app**」ボタンをクリックします。
5. 「Do you already have an app?」と聞かれるので、「**Yup, I have an app**」を選びます。
6. 次の3つを入力・選択します。
   - **Repository**：手順3で作ったリポジトリ（例：`あなたのGitHubユーザー名/us-stock-dashboard`）
   - **Branch**：`main`（そのままで問題ありません）
   - **Main file path**：`app.py`
7. 「**App URL**」欄は、公開されるURLの一部（サブドメイン）を自分で決めたい場合に入力します。空欄のままでも自動でURLが割り当てられます。
8. 「**Deploy**」ボタンをクリックします。

数十秒〜数分ほど待つと、必要なライブラリのインストールとアプリの起動が自動的に行われ、あなた専用のダッシュボードが公開されます。ライブラリの数が多いため、初回は3〜5分程度かかることがあります。

## 6. 動作確認・使い方

- 画面左のサイドバーにある「**📅 期間 (Focus Period)**」で、1日／1週間／1ヶ月を切り替えられます。
- データは取得後15分間キャッシュ（一時保存）されるため、15分以内に再読み込みしても表示は変わりません。すぐに最新化したい場合は、サイドバーの「**🔄 最新データに更新する**」ボタンを押してください。
- ページを開くたびに、その時点の最新データがその場で取得されます（決まった時刻に配信されるタイプのレポートではありません）。

## 7. うまく表示されないときは（トラブルシューティング）

- **「セクターデータの取得に失敗しました」「取得できませんでした」と表示される**
  → データ提供元（Yahoo!ファイナンス、openinsider.com、arkfunds.io）側が一時的に混雑しているか、アクセス制限がかかっている可能性があります。数分待ってから、サイドバーの更新ボタンを押すか、ページを再読み込みしてください。
- **株価データだけがずっと取得できない**
  → yfinance（株価取得に使っているライブラリ）は無料でYahoo!ファイナンスのデータを利用しているため、アクセスが集中すると一時的に制限されることがあります（`Too Many Requests` エラー）。時間をおいて再度お試しください。
- **しばらく使っていなかったらアプリが動いていない／「zzz…」と表示される**
  → Streamlit Community Cloudの無料アプリは、一定期間アクセスがないと自動的にスリープ（休止）します。画面に表示される「**Yes, get this app back up!**」のようなボタンを押すと、数十秒で再起動します。
- **コードを直したいとき**
  → GitHubのリポジトリ画面で該当ファイル（例：`app.py`）を開き、鉛筆マーク（✏️ Edit）をクリックして編集し、「Commit changes」を押すだけで、Streamlit Community Cloud側のアプリにも自動的に反映されます。

## 8. データの取得元について

- **株価・指数・暗号資産・金**：yfinance ライブラリ経由でYahoo!ファイナンスのデータを取得しています。
- **内部者クラスター買い**：openinsider.com（SEC Form 4の内部者取引情報をまとめた無料サイト）から取得しています。
- **ARK Invest売買動向**：arkfunds.io（ARK Investとは無関係の第三者が提供する無料の非公式API）から取得しています。

これらはいずれも無料で利用できる情報源ですが、提供元の仕様変更やアクセス制限により、一時的にデータが取得できなくなる場合があります。その場合はアプリ画面にその旨のメッセージが表示されます。
